# VideoTranscriber.ai 真人体验报告

> 体验日期：2026-10-27 ｜ 工具：Tabbit 浏览器 ｜ 账号：点击转录时弹出登录，由用户手动用 Google 登录

## 一、体验路径

| # | 操作 | 观察 |
|---|---|---|
| 1 | 打开首页 | 左侧栏导航 + 中间大工具框，首屏就能用；三个输入方式：Video/Audio、Link、Record |
| 2 | Link 标签粘贴 YouTube 链接（Me at the zoo，19 秒） | 点 "Get Transcript" 先**解析成预览卡片**（缩略图 + 标题 + 时长），再点 "Transcribe" 才开始，两步 |
| 3 | 第一次点 Transcribe | **弹出登录，未登录无法提交任务**（由用户手动完成 Google 登录，走 `auth/callback`）；登录后侧栏 "Sign in" 变成头像，高级额度从 0 变成 10；转录本身没开始，需要再点一次 |
| 4 | 再点 Transcribe | 任务进入首页下方 "My files"；高级额度 10→9（19 秒也扣 1 次） |
| 5 | 打开结果页 | 左边视频播放器 + 文字稿，右边 AI 面板；AI 笔记**自动生成**，语言跟随浏览器（输出中文） |
| 6 | 导出 | 弹窗：带/不带时间戳开关，TXT / DOCX / SRT / VTT / CSV；弹窗用 Esc 和点遮罩都关不掉（体验瑕疵） |
| 7 | 结果页标签 | Transcript（整段）/ Subtitles（逐句时间戳）/ Chapter（Medium、Short 两种粒度）；文字稿支持搜索、翻译 |
| 8 | AI 面板 | AI Notes、Ask AI（5 个预设问题 + 自由提问，回答后附 3 个追问建议）、MindMap（自动生成）、Infographic（手动生成，消耗高级额度） |
| 9 | Summarize 下拉 | **17 个总结模板 + 自定义 prompt**：智能总结、摘要、核心观点、章节总结、学习笔记、创作者二次创作、会议纪要、SOAP 医疗、病例讨论、庭审摘要、证据整理、访谈笔记、播客 Show Notes、新闻简报、时间线、博客文章、销售跟进 |
| 10 | Translate & Dub | 跳到 `/ai-video-translator`：原语言约 80 种、目标语言约 60 种、说话人数 1–8 / 自动，配音单次最长 20 分钟 |
| 11 | Basic 模式上传 26 秒 WAV | 浏览器**直传阿里云 OSS（美西 `oss-us-west-1`）**；显示进度百分比，总耗时约 42 秒；自动识别成会议录音，输出带 "负责人/时间节点" 表格的会议纪要；有 Speaker 01 标签 |
| 12 | Advanced Settings | 保留音频事件（笑声、掌声）、去口头禅/重复、Keyterms（专有名词提示） |
| 13 | Go Unlimited | 弹出和 /pricing 一样的套餐弹窗，年付 / 月付切换 |
| 14 | My Assets | 分 转录 / 翻译 / 录音 三个列表，显示名称、上传时间、时长、状态 |

体验结束时额度：基础 10→7（一次 Basic 转录 + 自动 AI 总结也会扣），高级 10→9。

## 二、关键发现

1. **"No sign-up" 是宣传话术，提交任务必须登录**：首页写着免注册，但点 Transcribe 就弹登录（流量数据里 `auth/callback` 有 18.6 万浏览量、`auth/register-confirm` 有 1.3 万，说明大量用户在这一步被要求登录）。登录后才送 10 次高级额度。这是它的拉新手段，也是用户流失点。
2. **AI 总结自动跑、模板按场景细分**：转录完不用再点，直接给出结构化笔记；Smart Summary 会自己判断内容类型（会议 → 会议纪要表格）。17 个模板同时也是 SEO 落地页的素材（医疗、法律、会议、播客页面都对应一个模板）。
3. **额度设计**：基础额度按天、高级额度按月，"一次" 按时长折算，最短也扣 1 次；AI 总结也算在基础额度里。
4. **Advanced 档服务商推测**：音频事件 / 清理口头禅 / keyterms 三项和 ElevenLabs Scribe、Deepgram Nova-3 的参数对应，大概率接的是这一类第三方 ASR（推测，没有直接证据）。
5. **基础设施**：上传走阿里云 OSS 美西节点 + 前端直传，团队很可能是国内背景。
6. **体验瑕疵**（我们可以做得更好的地方）：
   - 宣传免注册，实际提交就要登录；链接要点两次（Get Transcript → Transcribe），登录回来还得再点一次 Transcribe
   - 导出弹窗不好关
   - 结果页 URL 不变（还是 `/` 或 `/my-videos`），**没有可分享的独立链接**，也不利于 SEO
   - 19 秒的视频也扣一整次高级额度

## 三、对我们方案的影响

| 学到的 | 落到 TapeScript |
|---|---|
| 提交即要求登录 | **照做，不给白嫖**：点转录时必须登录；改进点是登录回来自动提交，不用再点一次 |
| 自动 AI 总结 + 场景模板 | Phase 1 就做"转录完成自动生成总结"；模板先做 5 个（智能总结、会议纪要、学习笔记、YouTube 摘要、博客文章），prompt 放 `prompts/` |
| 链接预览卡片 | 保留预览（让用户确认是哪个视频、多长），但**合并成一步**：贴链接 → 预览出来就自动开始 |
| 结果页没有独立 URL | 每个任务有独立的 `/t/[id]` 页面，可分享，可选择公开 |
| 导出格式 | TXT / DOCX / SRT / VTT / CSV + 时间戳开关，和竞品对齐 |
| 进度百分比 | 任务状态里加 `progress` 字段，前端显示 |
| Advanced Settings | 高级档接 Deepgram 或 ElevenLabs，直接开放 keyterms 和去口头禅两个开关 |

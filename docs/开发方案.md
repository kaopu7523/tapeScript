## 一、竞品拆解

### 1.1 一句话定位
**把任何视频 / 音频 / 链接（YouTube、TikTok、Facebook……）转成文字稿，再用 AI 做总结、笔记、翻译。** 免费、免注册即可用，靠额度限制转化付费。

### 1.2 流量结构（2026 年 9 月，全球）
- 月访问量约 **149 万**（首页 62.6 万 ≈ 42%）
- 渠道：搜索 56.8%、直接 32.8%、社交 4.3%、引荐 4.0%、邮件 1.2%，广告几乎为 0 → **纯 SEO 驱动**
- 按页面类型汇总（合并各语言版本）：

| 页面类型 | 月访问 | 说明 |
|---|---|---|
| 首页（各语言） | ~71 万 | 品牌词 + "video transcriber / transcribe video to text" |
| converter/youtube-to-mp4 | ~21.7 万 | 下载器，法/西/德/日语流量为主 |
| facebook-transcript-generator | ~13.4 万 | **82% 来自自然搜索，单页最强的转录类落地页** |
| converter/youtube-to-mp3 | ~11.4 万 | 下载器 |
| video-transcript-generator | ~7.7 万 | |
| tiktok-transcript-generator | ~4.6 万 | |
| video-to-text / youtube-to-transcript | ~6.1 万 | |
| youtube-subtitle-downloader | ~1.9 万 | |

**结论**：
1. 转录类落地页 + 多语言是流量主体；
2. YouTube 转 MP3/MP4 下载器约占 22% 流量，但有版权、DMCA、支付通道封号风险（见第七节）；
3. 长尾工具页（"xxx transcript generator"、"xxx to text"）是可规模化复制的 pSEO 模式。

### 1.3 关键词机会（Semrush US，1588 个词）
低 KD、竞品排名靠前的词值得优先做：

| 关键词 | 月搜索量 | KD | 备注 |
|---|---|---|---|
| tiktok transcript | 6,600 | 27 | KD 低 |
| tiktok transcript generator | 2,900 | 29 | KD 低 |
| transcrever video em texto | 2,400 | 26 | 葡语，KD 低 |
| transcribe youtube video no captions | 1,900 | 54 | 精准痛点 |
| video transcript generator free no file size or time limit | 480 | 55 | 商业意图 |
| correct speaker label / time coding transcripts | 4,400 / 3,600 | 10 | 功能词，KD 极低 |

核心大词（video to text、transcribe video to text、video transcript generator）KD 都在 57–78，新站短期内拿不下，**靠长尾 + 多语言先起量**。

### 1.4 功能清单（竞品现状）
- 输入：本地上传（单文件最大 500MB / 付费 5GB）、YouTube 链接、TikTok / Facebook / Instagram / X / Bilibili 链接
- 转录：多语言、说话人识别、时间戳、两档精度（basic / advanced）、批量 5 个
- AI 后处理：总结、AI Notes、AI Chat、思维导图、信息图
- 翻译：字幕翻译 200+ 语言、AI 配音（Dubbing）
- 导出：TXT / SRT / DOCX、带字幕视频下载
- 其他：My Assets 历史记录、API & MCP、桌面客户端、Chrome 插件、博客、竞品对比页（vs HappyScribe / TurboScribe / Descript …）、11 种语言

### 1.5 定价（竞品）

|---|---|---|---|---|---|
| Free | $0 | — | 20 分钟/天 | 20 分钟/月 | 500MB |
| Basic | $5.5 | $7 | 1000 分钟/月 | 200 分钟/月 | 5GB |
| Pro | $9 | $18 | 无限 | 1000 分钟/月 | 5GB |

**付费卡点**：每日时长额度、单文件大小、高级精度、AI 配音分钟数。"基础转录无限" 是最大卖点，背后靠的是很便宜的 ASR（推测 Whisper 类模型自部署或廉价 API）。

## 二、我们的定位与差异化

不追求一次复刻全部功能。先做竞品流量最大的那部分：**"链接/文件 → 文字稿 → AI 总结" 核心闭环 + 大量 SEO 落地页**。

差异化切入（选 1–2 个，不贪多）：
1. **登录墙后置但不省略**：首页、上传、贴链接预览都不用登录，点"转录"时必须登录（和竞品一致，不给白嫖）；登录回来自动继续提交，不用再点一次（竞品要再点一次）。
2. **转录 + 编辑器体验**：文字稿和音频同步高亮、点击跳转、在线改错字（竞品偏"出结果就走"）。
3. **导出格式更全**：TXT / SRT / VTT / DOCX / Markdown / PDF，带或不带时间戳、说话人。

## 三、技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| 框架 | Next.js 15+（App Router）+ TypeScript | SSR/SSG 利于 SEO；按规范只用 app/ router |
| UI | Tailwind CSS + shadcn/ui | 快 |
| 多语言 | next-intl | 首批只做 en + zh；英文无前缀（`/video-to-text`），中文 `/zh/...`；加语言只需改配置 + 加翻译文件 |
| 数据库 | PostgreSQL（Neon 或 Supabase）+ Drizzle ORM | |
| 鉴权 | Better Auth（Google OAuth + 邮箱魔法链接） | 开源、可控，不用存密码 |
| 支付 | Dodo Payments（首选）/ PayPal / Waffo | 见第五节"收款渠道" |
| 文件存储 | Cloudflare R2（前端直传 presigned URL） | 无出口流量费 |
| ASR 基础档 | Groq Whisper large-v3-turbo | 价格极低、速度快，支撑"基础无限" |
| ASR 高级档 | Deepgram Nova-3 或 AssemblyAI | 说话人识别、准确率高、支持 webhook |
| LLM | AI SDK v6 + 任意模型（总结/笔记/翻译） | 按规范统一 AI SDK v6，prompt 放 `prompts/` |
| 长任务队列 | Trigger.dev 或 Inngest | 转录是分钟级任务，不能放在 Vercel 请求里同步跑 |
| 媒体处理 Worker | 一台 VPS（Docker：yt-dlp + ffmpeg） | 链接下载、音频抽取、切片；Vercel 跑不了 |
| 部署 | Vercel（Web）+ VPS（Worker） | |
| 监控 | Sentry + Plausible/GA4 + Google Search Console | |

> 价格类信息（ASR 每小时成本等）上线前需按官网最新价格复核。

### 3.1 核心处理流程

```
用户上传文件 ──► R2 直传 ──┐
                            ├─► 创建 Job（DB: pending）──► 队列
用户粘贴链接 ───────────────┘
                                       │
                         ┌─────────────┴──────────────┐
                    YouTube 有字幕？                 其他
                         │是                          │
                  直接抓取字幕（秒级）        Worker: yt-dlp 下载音频
                         │                    ffmpeg 转 16k mono / 切片
                         │                            │
                         │                    ASR（Groq / Deepgram）
                         └─────────────┬──────────────┘
                                       ▼
                        存 segments（时间戳/说话人）→ Job: done
                                       ▼
                  前端轮询或 SSE 拿结果 → 编辑器展示 → 可选 AI 总结（流式）
```

关键点：
- **YouTube 优先抓字幕**：竞品宣传 "YouTube（有字幕）不限时长"，就是因为字幕抓取几乎零成本。
- **YouTube 下载需要住宅代理**：机房 IP 会被拦，代理费要算进成本。
- **错误直接展示给用户**：ASR / LLM 失败就把 Job 标成 failed、写清原因并退还额度，不返回假结果。

### 3.2 数据模型（初版）

```
users            id, email, name, image, plan, created_at
transcription_jobs
                 id, user_id, source_type(upload|youtube|tiktok|...),
                 source_url, r2_key, duration_sec, language, quality(basic|advanced),
                 status(pending|processing|done|failed), error_message, created_at, deleted_at
transcript_segments
                 id, job_id, start_ms, end_ms, speaker, text
ai_outputs       id, job_id, kind(summary|notes|translation), language, content, created_at
usage_ledger     id, user_id, job_id, minutes, quality, created_at   ← 额度扣减与退还
subscriptions    id, user_id, provider, provider_sub_id, plan, status, current_period_end
```
- 删除一律软删除（`deleted_at`），符合规范。
- **转录必须登录**：未登录可上传文件、贴链接看预览；点转录时弹登录，登录回来自动提交刚才的任务（上传的文件先存 R2，登录后用 r2_key 继续）。`/api/jobs` 未登录直接返回 401。
- 额度按 `user_id` 计；防小号：Google 登录为主，邮箱登录加 Turnstile，同 IP 每日新注册数设上限。

### 3.3 目录结构

```
app/
  [locale]/
    page.tsx                     首页（主工具）
    [tool]/page.tsx              所有 SEO 工具页共用一个模板
    pricing/page.tsx
    my-transcripts/page.tsx
    t/[jobId]/page.tsx           文字稿详情 + 编辑器
    blog/[slug]/page.tsx
    compare/[slug]/page.tsx
  api/
    upload-url/route.ts          生成 R2 presigned URL
    jobs/route.ts                创建任务
    jobs/[id]/route.ts           查询状态
    summarize/route.ts           AI 总结（流式）
    webhooks/dodo/route.ts
    webhooks/asr/route.ts
i18n/config.ts                   locales = ['en', 'zh']，加语言只改这里
messages/{en,zh}.json            界面文案（按钮、提示、报错）
content/tools/{en,zh}/*.json     每个工具页的文案（标题/H1/FAQ/步骤）
prompts/                         summary.md、notes.md、translate.md（版本化）
lib/                             db、r2、asr、auth、quota
worker/                          独立 Docker 服务：yt-dlp + ffmpeg + 调 ASR
```
SEO 工具页 = **一个模板 + 一份 JSON 配置**，新增页面只加配置，不加代码。

## 四、SEO 方案

1. **工具页矩阵**（第一批 15 个，按流量与 KD 排序）：
   `video-to-text`、`youtube-transcript-generator`、`youtube-to-transcript`、`tiktok-transcript-generator`、`facebook-transcript-generator`、`instagram-transcript-generator`、`video-transcript-generator`、`mp4-to-text`、`mp3-to-text`、`audio-to-text`、`video-to-srt`、`youtube-subtitle-downloader`、`video-summarizer`、`speaker-label-transcription`、`time-code-transcription`
2. **多语言**：
   - **第一阶段只做英语 + 简体中文**。英语面向 SEO 主市场；中文版方便你审核内容。
   - **流程**：每个页面同时生成 en 和 zh 两版 → 你审中文版（意思、卖点、语气）→ 有问题改中文并同步改英文 → 审完定稿。
   - **再扩语言**：中文审过、页面数据稳定后，用 LLM 以定稿的英文为源，批量翻译到 es / fr / pt / de / ja（竞品非英语流量占比很高），之后再加 ko / id / ru / zh-TW。新增语言只需在 `i18n/config.ts` 加一项，再补对应的 `messages` 和 `content` 文件，不改代码。
   - 每页都要有 hreflang 和独立 meta；sitemap 按语言自动生成。
3. **每页内容**：可直接使用的工具框（首屏）+ 3 步说明 + 功能点 + 使用场景 + FAQ（FAQPage schema）+ 内链到相关工具。文案要原创，不照搬竞品。
4. **竞品对比页**：tapescript vs TurboScribe / HappyScribe / Descript / VideoTranscriber。
5. **博客**：围绕 "how to get transcript of youtube video"、"how to transcribe tiktok" 这类教程词。
6. **技术 SEO**：SSG、sitemap 分语言、Core Web Vitals 达标、OG 图自动生成。
7. **外链**：Product Hunt、各类 AI 工具导航站、Reddit / Indie Hackers。

### 收款渠道

| 渠道 | 定位 | 说明 |
|---|---|---|
| Dodo Payments | **首选，MVP 只接这一个** | MoR（代收代缴销售税/VAT），支持订阅和 webhook，用户用信用卡付款 |
| PayPal（PayPal.cn 商家账号） | 第二个接入 | 部分海外用户习惯用 PayPal；不是 MoR，税务要自己处理 |
| Waffo | 备选 | Dodo 审核不过或费率不合适时替换 |

- 先只接 Dodo，跑通订阅 → webhook → 额度联动，再按用户反馈加 PayPal，避免一开始维护多套对接。
- `subscriptions.provider` 字段区分渠道，各渠道的 webhook 各写一个 route（`/api/webhooks/dodo`、`/api/webhooks/paypal`）。
- 接入前逐个确认：主体资质要求、费率、是否支持订阅自动续费、退款/拒付 webhook、提现到国内的方式（以各平台官网最新条款为准）。

**单位成本粗估**（上线前复核）：基础档 Groq Whisper 约 $0.04/小时音频；高级档 Deepgram 约 $0.25–0.3/小时。Pro 用户即使用满上限，毛利也健康。真正的成本风险在 **YouTube 代理流量** 和 **滥用**，需要做限流和设备指纹。

## 七、风险与需要你决策的事

1. **是否做 YouTube 转 MP3/MP4 下载器**：竞品约 22% 流量来自这里，但存在版权和 DMCA 投诉风险，Stripe/Paddle 等支付通道和 Google AdSense 都可能因此封号。**建议 MVP 不做**；如果一定要做，放到独立子域名或独立站，和主站支付体系隔离。
2. **YouTube 抓取稳定性**：YouTube 会持续升级反爬，yt-dlp 需要常更新，代理是持续成本。
3. **滥用与成本失控**：已强制登录，但仍要防批量注册小号刷免费额度（同 IP 注册上限、邮箱登录加 Turnstile）。
4. **隐私合规**：用户上传的音视频默认 7 天后自动删除源文件，只保留文字稿；隐私政策、条款、版权投诉页上线前必须有。
5. **收款**：已定 Dodo Payments（首选）/ PayPal / Waffo，接入前确认各平台对你主体的审核要求。

## 八、产品分析思考清单（补全）

| 问题 | 回答 |
|---|---|
| 解决什么问题 | 视频/音频/链接 → 文字稿，并进一步变成总结、笔记、字幕、译文 |
| 用户是谁 | 学生、教师、会议参与者、内容创作者、研究者、记者、销售/客服 |
| 如何找到用户 | 搜索 56.8%（长尾工具页 + 11 种语言）、直接访问 32.8%（复访与品牌） |

| 付费卡点 | 每日时长、单文件大小、高级精度、AI 配音分钟数 |
| 不容易的地方 | 低成本 ASR 才能撑起"基础无限"；YouTube 稳定抓取；几百个多语言落地页的内容生产 |
